# 🌊 Web Dashboard WP-4: Sistem Pemantauan Level Air

Selamat datang di repositori Web Dashboard untuk proyek **Sistem Informasi Pemantauan dan Pengendalian Level Air Berbasis IoT di RSA UGM**. Repositori ini menaungi antarmuka berbasis *browser ultrawide* untuk operator rumah sakit dan juga berperan sebagai peladen *Backend-for-Frontend (BFF)*.

## 📂 Struktur Dokumentasi (Wajib Dibaca)
Sebelum mulai menulis kode atau membuat Pull Request, sangat disarankan bagi seluruh anggota tim untuk membaca spesifikasi teknis dan panduan di bawah ini:

1. **[Kebutuhan Proyek (Requirements)](./requirements.md)**: Gambaran besar fitur fungsional.
2. **[Panduan Developer (Guideline)](./guideline.md)**: Instruksi `git clone`, instalasi via `pnpm`, dan konvensi cabang.
3. **[AI Actions & Prompting](./action.md)**: Panduan *prompting* AI (ChatGPT/Claude/Gemini) agar *coding* sesuai arsitektur kita.
4. **[Tech Stack](./Techstack.md)**: Pemaparan Next.js, Tailwind CSS, dan penjelasan *Sweet Spot* BFF.
5. **[Arsitektur](./Architecture.md)**: Standar *Layout* modular dan struktur pemecahan *routes*.
6. **[Scope Halaman](./Scope.md)**: Rincian halaman spesifik, interaksi *Single-lock*, dan daftar tangki aktual.
7. **[Security & AAA](./Security-AAA.md)**: Kebijakan Autentikasi, *RBAC*, dan manajemen *Cookies* super aman.

> **Catatan Tim**: Repositori Web ini adalah pecahan (WP-4) dari sistem terintegrasi yang lebih besar. Sistem backend sejati berada di WP-3, dan aplikasi ponsel petugas ada di repositori Mobile. Hubungi *Project Leader* jika menemukan ambiguitas lintas tim.
